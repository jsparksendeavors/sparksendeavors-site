Support

Big Gym Guy is a free iPhone workout log and program planner from Sparks Endeavors. It is coming to the App Store and is not listed yet. Help is by email at josh@sparksendeavors.com.

Write to josh@sparksendeavors.com. That is the support address. There is no phone line and no account for us to look up.

In the email, say what you were trying to do and what happened instead. Your iPhone model and iOS version help if you have them. If a file is part of the problem — an import that failed, or an export you are moving — attach it if you are comfortable sending it. Do not send medical records.

How do I import a program?

Big Gym Guy can import a program from a file. There is no account and no online program library, so the file has to be one you can open on your iPhone, such as a program file you exported earlier or saved in Files.

Use import in the app and choose that file. The program is then stored on this iPhone, with the rest of your log. If the import does not come in, email josh@sparksendeavors.com, describe what you expected, and attach the file if you are willing to share it.

Does starting a program switch Home automatically?

No. Starting a program does not switch Home automatically. Home keeps showing the program already set there. Starting a program leaves Home as it is.

Does Big Gym Guy read Apple Health?

No. Apple Health is write-only. If you allow it, the app can save a finished workout to Apple Health: a traditional strength-training workout with a start time, an end time, and an estimate of active energy. It does not read your workouts, heart rate, or any other Health data.

Health data is not used for advertising and is not sold. You can refuse access when the app asks, and you can change the permission later in iOS Settings. The full detail is in the privacy policy.

How do I export my data?

Use export in the app to make a file of your Big Gym Guy data. That file stays on your iPhone until you send it or save it somewhere else. Email, AirDrop, and Files can all take a copy off the device. Big Gym Guy does not upload the file to a Sparks Endeavors server.

Keep the file if you want a backup you can import later, including on another iPhone. Deleting the app deletes the workout history and journal notes stored in the app. It does not delete copies you already exported.

Is there a login? Where is my log?

On your iPhone. This version has no account, no sign-in, no cloud backend, no ads, no third-party analytics, and no in-app purchases. We cannot pull up your workouts from our side, because we never receive them.

The rest timer did not alert me

Notifications are only for the rest timer. They are not used for anything else. If an alert does not appear when a rest ends, allow notifications for Big Gym Guy in iOS Settings. You can turn that permission off if you do not want the alert.

Is this medical advice?

No. Big Gym Guy is not a medical device and it is not medical advice. Talk to a doctor before you start a new exercise program. The terms of use say the same thing.
